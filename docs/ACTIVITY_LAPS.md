# Activity laps and comparisons

The activity overview defaults to original watch laps. It shows timer duration
(elapsed duration when unavailable), distance, recorded average HR/speed, HRmod
and Vflat. A separate selector exposes Intervals.icu intervals. Selecting a row
sets the same time range on both comparison charts. On phones each measured
value appears above its modeled value; missing values remain dashes, including
when a model has no valid support.

## Source and persistence

Intervals.icu supplies detected/edited intervals in `icu_intervals`. These are
not necessarily the laps recorded on the watch. During the existing background
refresh, `/activity/{id}/file` supplies the original FIT/TCX file. Do not use
`/fit-file`, which can contain intervals regenerated by Intervals.icu.

Only compact lap summaries persist in a versioned envelope in the catalog's
existing `intervals` JSON. File metadata fingerprints allow reuse on subsequent
refreshes; transient failures retry at the next refresh. Original file access
is optional and cannot invalidate a successful activity import. No database
migration or scientific model version change is required. Existing activities
gain original laps at the next normal data refresh; opening an activity never
downloads an original file. Initial historical backfill adds one provider file
request per eligible activity. This should be measured during staging validation.

The cache envelope is stripped from public detail/view responses. The activity
view derives comparisons from the same generation-pinned catalog and model
payloads already loaded for that request. It makes no extra database request.

## Comparisons

Preserve FIT timer/elapsed durations separately and retain fractional seconds.
Use explicit elapsed-time bounds, never provider sample indices as seconds.
TCX without trackpoint times preserves timer summaries but cannot provide
trustworthy elapsed bounds for model comparisons.

Lap HRmod is integrated over valid raw/HRmod pairs. Validated smart-recording
spans use linear interpolation split at exact lap boundaries; recording stops
and unsupported gaps do not become evidence. Vflat uses the independent
`speed_test_series`, preserving its right-aligned one-second support and speed
exclusions. Load-completion speeds never replace measured speed or Vflat.
Prefix integrals avoid scanning an entire activity separately for every lap.

The primary measured values retain the device's own summaries, matching Garmin.
The expandable comparison details provide measured/model means on identical
valid support and the number of supported seconds. These can differ from the
whole-lap watch summary. Graphs use display decimation; averages use full stored
resolution. This is a presentation change: load, recovery, 7/40, nutrition and
planning inputs remain unchanged.
