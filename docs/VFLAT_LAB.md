# Vflat Lab v1 — емпирична TCX лаборатория

`vflat_lab_app.py` е самостоятелно Streamlit приложение за калибриране на
теренно-нормализирана скорост. То не е включено в продукционния pipeline и не
променя основния `app.py`.

## Стартиране

```bash
python -m pip install -r requirements.txt
python -m streamlit run vflat_lab_app.py
```

За Streamlit Community Cloud:

```text
Repository: Dimcho1988/biathlon-program-generator-2
Branch: codex/vflat-empirical-tcx-lab-v1
Main file path: vflat_lab_app.py
```

## Модел

Стационарната функция е насищаща се:

```text
R(g) = exp{-A[1-exp(-((g-g0)/B)^p)]}
Vstat = v / R(g)
```

Крайният кандидат включва отделни емпирични термини за положително и
отрицателно ускорение и ограничени между 0 и 1 памети след спускане и
изкачване:

```text
Vflat = Vstat + K+ max(a,0) - K- max(-a,0) - Cd D(t) + Cu U(t)
```

Около разпознатите преходи регулируем слой може частично да приближи кандидата
към центрирана локална медиана. Това е post-activity емпирична стабилизация, а
не streaming оценка; силата ѝ остава видима и може да бъде нула.

Всеки параметър има `help` обяснение в Streamlit. Промените се прилагат към
всички качени файлове, за да не се настройва неусетно отделен модел за всяка
активност.

## Начален preset

Началните стойности са консервативен работен кандидат от наличните ролкови TCX
записи и предходните анализи. Те не са окончателно валидиран общ модел.

Предварителната настройка използва стабилни 15-секундни части и повторни
работни обиколки от 11 Z3 файла. При тези файлове средният централен 90%
диапазон е приблизително 14.9 km/h за стационарния слой и 7.7 km/h за крайния
кандидат. В контролния файл `Валя_банско_3 зона.tcx` резултатът е 16.86 срещу
6.15 km/h. Този файл съвпада с по-ранен запис под друго име, затова числата са
вътрешна калибрационна диагностика, а не независима валидация.

Целта 5 km/h е достигната в част от записите, но не във всички. Затова preset-ът
е отправна точка за експертна настройка, а не готов коефициент за onFlows.

## Критерии за проверка

- при предварително обозначена равномерна Z3 работа централният 90% диапазон на
  Vflat се цели около 5 km/h;
- остатъчната корелация с наклона и ускорението трябва да намалява;
- истинските спринтове и промени в интензивността трябва да останат видими;
- финалният preset трябва да се провери върху спортисти и активности, които не
  са използвани при настройването;
- пулсът е диагностичен слой, не директна цел на Vflat.

## Ограничения

Лабораторията не измерва механична мощност и не доказва физиологична
еквивалентност. TCX Smart Recording не е истински 1 Hz; интерполацията се
извършва само в непрекъснати блокове, а паузи над зададения праг ги разделят.
Изходът е експериментален треньорски модел до последваща независима валидация.
